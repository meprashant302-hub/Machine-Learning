# Heart Disease Prediction

This is a machine learning project where I explored a heart disease dataset and tried to understand which patient-related features can be useful for predicting heart disease.

I made this project while learning the basics of machine learning, data analysis and model building.

## About the Dataset

The dataset contains **918 records and 12 columns**.

Some of the features included are:

* Age
* Sex
* Chest Pain Type
* Resting Blood Pressure
* Cholesterol
* Fasting Blood Sugar
* Resting ECG
* Maximum Heart Rate
* Exercise Angina
* Oldpeak
* ST Slope

The target column is:

* `HeartDisease`

## How to Run

1. Clone this repository.

2. Open `Heart.ipynb` using Jupyter Notebook or JupyterLab.

3. Make sure `heart.csv` is present in the same folder as the notebook.

4. Run the notebook cells from top to bottom.
